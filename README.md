A front page of the world's news on **Wednesday 18 November 2026**, drawn from scratch by one Node 22
program with the standard library only (its own 5x7 pixel font, vector icons, supersampling and PNG encoder).

Stories: Trump lands in Shenzhen for APEC as Xi and Putin meet; Iranian drones target a US base in Kuwait;
Nvidia's record quarter halts a tech selloff; COP31 row over a fossil-fuel exit; WHO urges Gaza aid as floods
hit camps; Germany sends air-defence aid to Ukraine; Mauritius warns the UK over the Chagos Islands; plus
Mongolia, Paraguay and the GTA VI launch.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

It writes `out/entry.png` (1024x1024 PNG), byte-identical on every run.
